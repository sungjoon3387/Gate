# Gate

전력기기 3종목과 QQQ의 매수 게이트. 매일 아침 06:30 전에 갱신되고, 알림은 보내지 않습니다.
페이지를 열었을 때 대부분의 날은 "오늘 조치 없음"이 정답입니다.

## 파일

| 파일 | 역할 | 누가 고치나 |
|---|---|---|
| `collect.py` | 시세 수집·지표 계산 (표준 라이브러리만) | 자동 |
| `brief.py` | 금리·환율 3줄 브리핑 (선택) | 자동 |
| `data.json` | 수집 결과 | 자동 |
| `tranches.json` | 계단 발화 이력 | 자동 |
| `holdings.js` | **보유·논거·매매기록** | 직접, 월 1회 |
| `index.html` | 페이지 | 거의 안 고침 |

## 배포

Semi Atlas와 같은 구성입니다.

1. 새 저장소를 만들고 위 파일을 올립니다.
2. Settings → Actions → General → Workflow permissions를 **Read and write**로.
3. Actions 탭 → "Gate 데이터 갱신" → Run workflow로 한 번 수동 실행.
   `data.json`과 `tranches.json`이 커밋되면 정상입니다.
4. Cloudflare Pages에서 저장소를 연결. 빌드 명령 없음, 출력 디렉터리는 루트(`/`).
5. 폰에서 열어 홈 화면에 추가. manifest가 들어 있어 주소창 없이 뜹니다.

### 브리핑을 켜려면 (선택)

Settings → Secrets and variables → Actions → New repository secret
이름 `ANTHROPIC_API_KEY`. 없으면 그 단계는 조용히 건너뜁니다.

## 갱신 시각

cron이 두 개 걸려 있습니다.

- `20 20 * * 1-5` → **05:20 KST** (미국 서머타임: 장 마감 05:00)
- `15 21 * * 1-5` → **06:15 KST** (미국 표준시: 장 마감 06:00)

겨울에 05:20에만 돌리면 전전날 종가를 보게 되므로 두 번 돌립니다. 뒤에 도는 쪽이 덮어씁니다.
GitHub Actions 스케줄은 부하에 따라 5~15분 늦어질 수 있어서, 상단 기준시각 배지가 8시간을 넘으면
노란색으로 바뀝니다. 늦게 도는 것보다 늦은 걸 모르는 게 위험합니다.

06:30에 있는 데이터: 미국주식 전일 종가, 미국채 금리, 달러지수, 달러원(서울 새벽 마감가).
없는 데이터: HD현대일렉트릭 당일가 — 국내장은 09:00 개장이라 전일 종가가 표시됩니다.

## 규칙

- **계단**: 52주 고점 대비 −15 / −25 / −35%. 각 단은 1회만 발화하고, 신고점이 나오면 초기화됩니다.
- **게이트**: 전력기기 3종목 합이 35%를 넘으면 신규 매수 신호를 띄우지 않습니다.
  **매도는 강제하지 않습니다.** 초과분은 다음 적립을 QQQ로 보내 희석합니다.
- **동시신호**: 세 종목 중 둘 이상이 같이 계단에 닿으면 카드를 하나로 묶고 "한 종목만"으로 표시합니다.
  같은 논거에 걸린 종목들이라 한 번에 사면 상한을 한 번에 뚫습니다.
- **논거 잠금**: `holdings.js`의 thesis가 90일을 넘으면 그 종목의 매수 신호가 잠깁니다.
  가격 신호는 어디서든 구하지만, 논거가 살아 있는지 묻는 장치는 여기밖에 없습니다.
