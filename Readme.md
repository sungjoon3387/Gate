# Gate

매일 아침 출근길 30초 안에 **"오늘 할 게 있나 없나"** 에 답하는 개인 투자 판정 페이지.

수익률을 보여주는 화면이 아니다. 그건 증권사 앱이 이미 잘한다.
Gate가 하는 일은 **감정이 아니라 규칙이 매수·매도를 정하게 만드는 것**이다.

- **호스팅** — Cloudflare Workers (`gate.sungjoon3387.workers.dev`)
- **저장소** — GitHub Public (키는 반드시 Secrets로만)
- **갱신** — GitHub Actions, 평일 2회 (한국시간 05:20 / 06:15)
- **운영 시작** — 2026년 9월
- **창구 종료** — 2029년 9월 (3년 뒤 구조 재검토)

---

## 1. 설계 철학

### 1.1 세 가지 원칙

1. **팔지 않고, 안 산다** — 상한 초과 시 매도가 아니라 신규 매수 정지. 초과분은 급여 적립을 코어로 보내 희석한다.
2. **자금 유입이 수익률보다 크다** — 2천만원 규모에서 자산 곡선을 만드는 건 순유입액이지 수익률이 아니다.
3. **논거 없으면 매수 없음** — 분기 갱신 미이행 시 해당 종목 매수 신호가 잠긴다.

### 1.2 Gate는 예측하지 않는다

"다음 달 금리는 이렇게 될 것"이라는 문장을 매일 아침 읽으면, 그게 맞든 틀리든 판단이 그 문장에 끌려간다.
그래서 Gate는 **예측 대신 "언제 무엇을 확인할지"** 를 적는다.

화면의 모든 판정은 **오늘 관측된 숫자**에서 나오고, 과거 사례는 "이번에도 그렇게 된다"가 아니라
**"이 판정이 떴을 때 실제로 무슨 일이 있었나"** 의 기록이다. 같은 판정에 상반된 결과를 나란히 둔 것도 그래서다.

### 1.3 조용한 날이 정상이다

문턱은 종목마다 **연 2~3회** 나오도록 각 종목의 실제 이력에서 역산한다.
대부분의 날은 "오늘 조치 없음 · 적립만"이 맞다. 매일 할 일이 생기는 도구는 이미 고장난 것이다.

## 2. 파일 구조

### 2.1 화면

| 파일 | 역할 | 줄 수 |
|---|---|---|
| `index.html` | 탭 4개(오늘·금리환율·보유·기록), 게이트 비중, 트랜치 판정, 보유 분해 | ~525 |
| `holdings.js` | **수동 입력** — 보유 수량·평단·매매 기록·논거 | ~58 |
| `thesis.js` | 종목별 논거 카드 (논지·근거·반증조건·추적지표) + 렌더러 | ~359 |
| `macro.js` | 매크로 판정·계좌 번역·확인 일정·인과 사슬·과거 사례 | ~785 |
| `perf.js` | 세후 성과, 시중금리 대비 비교, 내부수익률 | ~216 |
| `refresh.js` | 수동 새로고침 버튼 (브라우저 캐시 우회) | ~171 |

### 2.2 수집

| 파일 | 역할 | 출력 |
|---|---|---|
| `collect.py` | 종목·지수 가격, 200일선 이격도, RSI, 종목별 문턱 자동 보정 | `data.json`, `tranches.json` |
| `macro.py` | FRED·야후 매크로 지표, 6개 인과 사슬 판정, 전일 대비 변화 감지 | `macro.json`, `macro_history.json` |
| `watch.py` | 반증 조건 관련 뉴스 감시 (구글 뉴스 RSS + SEC EDGAR) | `watch.json` |

### 2.3 설정

- `.github/workflows/update.yml` — 수집 → 커밋 → 푸시 (rebase 3회 재시도)
- `_headers` — Cloudflare Pages 전용. **Workers에서는 동작하지 않음**

### 2.4 스크립트 로드 순서 (`index.html` 하단)

```html
<script src="thesis.js"></script>
<script src="refresh.js"></script>
<script src="macro.js"></script>
<script src="perf.js"></script>
```

> `index.html` 의 `render()` 가 `$('#macro').innerHTML` 을 통째로 덮어쓰기 때문에,
> `macro.js` 와 `perf.js` 는 한 번 붙이고 끝내지 않고 **MutationObserver + 1초 폴링으로 계속 다시 붙인다.**

## 3. 데이터 파이프라인

```
GitHub Actions (평일 05:20 / 06:15 KST)
  ├─ collect.py   → data.json, tranches.json
  ├─ macro.py     → macro.json, macro_history.json
  ├─ watch.py     → watch.json          (continue-on-error)
  └─ commit & push (fetch → rebase → push, 3회 재시도)
        ↓
Cloudflare Workers 재배포
        ↓
브라우저 — fetch 후 판정 렌더
```

### 3.1 소스 우선순위

| 데이터 | 1순위 | 2순위 | 3순위 |
|---|---|---|---|
| 미국채 금리 | FRED | Stooq | 야후 |
| 환율 3종 | **data.json (야후 일간)** | FRED | — |
| 닛케이·구리 | data.json | 야후 직접 | 생략 |
| 한국 금리 | **FRED (OECD 취합)** | — | — |

**환율을 FRED에서 안 받는 이유** — 연준 H.10 통계가 **주 1회 발표**라 최대 일주일 늦다.
2026-09-19에 환율 3종만 멈춰 있던 사고가 이것이었다. `collect.py` 가 받은 야후 일간 값을 쓴다.

**한국 금리를 ECOS에서 안 받는 이유** — 한국은행 ECOS가 **해외 IP 접근을 자주 끊는다.**
GitHub Actions는 미국 서버라 `Max retries exceeded` 가 반복됐다. FRED의 OECD 취합 월간 데이터로 대체.

### 4.2 2층 — 인과 사슬 6개

#### ① 연준이 실제로 한 일
`FOMC 결정 → 정책금리 → 한미 금리차 → 환율`

판정: `인상 확정` / `인하 확정` / `인상 사이클 진행` / `동결`
→ 예상이 아니라 **실행된 사실**만 본다. 20일 내 정책금리 변동으로 판정.

#### ② 커브 모양이 말하는 것
`연준 정책 기대 → 커브 구간별 반응`

판정: `베어 플래트닝` / `베어 스티프닝` / `평행 이동`
→ 60일 변화폭으로 5년 vs 30년 비교.
**짧은 쪽이 앞장서면 "연준이 올릴 것 같다", 긴 쪽이 앞장서면 "나라 빚이 걱정된다"** — 후자가 훨씬 나쁘다.

#### ③ 금리 → 조달비용 → AI 캐펙스 → 전력기기
`실질금리 ↑ → IG 회사채 스프레드 → 하이퍼스케일러 조달 → 데이터센터 발주`

판정: `조기 경보 — 하이일드 선행` / `확대 — 경고` / `소폭 확대 — 관찰` / `안정`

| 조건 | 판정 |
|---|---|
| IG 60일 ≥ +0.25%p | 확대 — 경고 |
| HY 60일 ≥ +0.75%p 이고 IG < +0.25%p | **조기 경보 — 하이일드 선행** |
| IG ≥ +0.10%p 또는 HY ≥ +0.35%p | 소폭 확대 — 관찰 |
| 그 외 | 안정 |

**이 사슬이 포트폴리오의 목숨줄이다.** 금리가 캐펙스를 죽이는 게 아니라 스프레드가 죽인다.
투자등급은 가장 늦게 벌어지므로 하이일드를 조기 경보로 함께 본다 (2007년에도 하이일드가 먼저 움직였다).

#### ④ 유가 → 물가 → 연준 / 원가
`유가 ↑ → 헤드라인 물가 → 근원 물가 → 추가 인상 / 구리·물류비 → 전력기기 마진 / 한국 무역수지 → 원달러`

판정: `경고` (110달러↑ 또는 60일 +30%) / `관찰` (90~110달러) / `중립` (90달러↓)

#### ⑤ 일본 정상화 → 캐리 청산 → 내 자산
`일본 금리 ↑ → 미 국채 본국 회귀 → 미 장기금리 ↑ / 엔 급등 → 위험자산 청산 → 원화 약세`

판정: `청산 진행 — 경고` / `엔 강세 — 관찰` / `캐리 유인 축소 — 관찰` / `안정`

**엔화와 닛케이가 같이 움직이는지가 핵심.** 엔 20일 −3% 이상 **그리고** 닛케이 −5% 이상이면 청산.
엔화만 움직이면 다른 이유다.

#### ⑥ 연준 → 달러 → 원화 → 내 원화환산 수익률
`미 실질금리 → 달러인덱스 → 원/달러 → 보유 해외자산 평가액`

판정: `원화 강세 — 역풍` / `원화 약세 — 순풍` / `중립` (20일 ±10원)

### 4.3 3층 — 분기 맥락 (수동, 판정 미연결)

`macro.js` 상단 `MACRO_CONTEXT.blocks` 에서 분기 1회 갱신.

| 지역/주제 | 비중 | 요지 |
|---|---|---|
| 중동 | 높음 — 직접 경로 | 오일머니가 유가가 아니라 **AI 인프라 직접투자**로 들어온다. 국부펀드 발표가 곧 수주 파이프라인 |
| 중국 | 낮음 — 인과가 길다 | TIC 데이터 2개월 지연, 북미 전력기기 시장은 사실상 차단. 판정에 안 씀 |
| 메모리 가격 | 중간 — 캐펙스 착시 | 서버 비용의 최대 절반. **캐펙스 금액이 늘어도 지어지는 양은 덜 늘 수 있다** |
| 전기요금 | 중간 — 확장의 사회적 상한 | 데이터센터 반대 여론의 실체. AI 캐펙스를 멈추는 건 금리가 아니라 정치일 수 있다 |
| 한국 | 중간 — 환율 수급 | 국민연금 환헤지, 서학개미 순매수, 반도체 수출 (= 급여·성과급 선행지표) |

### 4.4 변화 감지

`macro_history.json` 에 180일치 지표값과 판정을 쌓아 **어제와 달라진 것만** 화면 위에 띄운다.

- **판정 전환** — 주황 박스. 가장 중요한 뉴스
- **의미 있게 움직인 지표** — 지표별 문턱 (10년물 0.05%p, 유가 2달러, 원/달러 8원)
- **5년 최고·최저 경신**
- 각 사슬 배지 옆 **"N일째 유지"**

변화가 없으면 "어제와 의미 있게 달라진 지표가 없습니다" 한 줄. 억지로 할 말을 만들지 않는다.

### 5.2 트랜치 — 200일선 이격도

- 문턱은 각 종목의 **실제 2년 이력에서 연 2~3회 나오는 지점**을 역산해 매일 재계산
- 추세선이 올라가면 문턱도 같이 올라간다
- **급등** → 보유량 30% 매도 (QQQ 제외)
- **급락** → 보유량 30% 추매
- 문턱보다 10%p 더 내려오면 → "규칙보다 논거가 먼저" 로 전환
- 20/60/200일선 배열은 **맥락으로만 표시, 트리거 아님**

### 5.3 논거 만료

`holdings.js` 의 `thesis.updated` 로부터 **90일** 경과 시 해당 종목 매수 신호 잠금 + 빨간 배지.

## 7. 논거와 반증 조건

### ETN (Eaton) — 위성
**논지** — 데이터센터 내부 배전·UPS. 수요처에 가장 가깝고 수주가 이미 실적으로 넘어오고 있다.

| 추적 지표 | 값 | 이전 |
|---|---|---|
| 수준 — Electrical Americas book-to-bill | 1.2 | 1.2 |
| **가속도 — 미주 수주 증가율** | **+33%** | +42% (9%p 감속) |
| 질량 — 수주잔고 커버리지 | 약 2분기 | $14.5B / 분기 $7.5B |
| 참고 — 부문 영업이익률 | 25.6% | 30.0% (440bp 하락) |

**반증 조건**
- Electrical Americas 마진이 분기 순차 +150bp 개선 가이드에 실패하고 두 분기 연속 하단
- book-to-bill 1.0 하회
- 2030년 32% 마진 목표에서 후퇴 발언
- `[정치]` 무역 중단·추가 관세 발효로 건설 비용 상승, 실적 콜에서 발주 지연 언급
- `[정치]` 연준 독립성 훼손이 장기금리로 전이 → 커브 스티프닝 전환 (Gate 자동 판정)

**리스크** — Q1'26 인수 $110억 집행 + 자사주 매입 중단으로 부채 증가. 하반기 EBITDA가 밀리면 레버리지가 노출된다.

### GEV (GE 버노바) — 위성
**논지** — AI 전력 수요의 최상류(발전). 공급이 수요를 못 따라가 가격이 먼저 오른다.

| 추적 지표 | 값 | 이전 |
|---|---|---|
| 수준 — 가스터빈 수주잔고+슬롯예약 | 116GW | 100GW |
| 가속도 — 분기 증가폭 | +16GW | **다음 분기 +10GW 아래면 둔화 진입** |

"수주잔고는 훌륭한데 손익은 미스"가 반복되는 패턴.

### QQQ — 코어
**논지** — 30년 자산. 전망으로 사고팔지 않는다. 매도 로직 영구 제외.
**반증 조건** — 해당 없음. 다만 지수 하락과 함께 빅테크 캐펙스 가이던스가 같이 꺾이면 "금리 탓"이라는 해석이 틀린 것.

**코어는 발주하는 쪽, 위성은 받는 쪽** — 분산이 아니라 한 흐름의 앞뒤를 나눠 산 것.

### JEPQ — 정리 대상
**논지** — 손익분기 대비 **+3% 도달 시 전량 매도**. 대금은 QQQ 약 66% / 전력기기 약 34%로 재배분.

> **미해결** — +3%가 원화 기준인지 달러 기준인지 미정.
> 환율에 따라 도달 시점이 완전히 달라진다. 원화 기준이면 중동 정세가 매도 시점을 정하는 셈이 된다.

**리스크** — 2022년 이후 4년간 $54~62 박스. 상방 절삭이 이론이 아니라 실측이다.
+3%를 기다리는 동안 그만큼 코어 복리가 뒤처진다.

### 9.3 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| Actions `! [rejected] (fetch first)` | 수동 커밋과 자동 수집 충돌 | `fetch → rebase → push` 3회 재시도 (적용됨) |
| 새 데이터가 커밋 안 됨 | `git add` 목록 누락 | `macro_history.json` 등 추가 확인 |
| 환율만 며칠째 그대로 | FRED H.10 주 1회 발표 | `data.json` 우선 (적용됨) |
| macro 블록이 안 보임 | `render()` 가 innerHTML 덮어씀 | MutationObserver로 재부착 (적용됨) |
| 페이지가 옛날 코드 | 브라우저 캐시 | 주소에 `?v=숫자`, 또는 새로고침 버튼 |
| `_headers` 무효 | **Workers는 Pages 전용 기능 미지원** | Worker 코드에서 응답 헤더 직접 설정 필요 |

### 9.4 워크플로

```yaml
name: Gate 데이터 갱신
on:
  schedule:
    - cron: '20 20 * * 1-5'
    - cron: '15 21 * * 1-5'
  workflow_dispatch: {}
permissions:
  contents: write
jobs:
  collect:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.12'
      - run: pip install requests
      - run: python3 collect.py
      - name: Collect macro
        env:
          FRED_API_KEY: ${{ secrets.FRED_API }}
          ECOS_API_KEY: ${{ secrets.ECOS_API }}
        run: python3 macro.py
      - name: Watch falsifiers
        continue-on-error: true
        run: python3 watch.py
      - name: Commit and push
        run: |
          git config user.name gate-bot
          git config user.email gate-bot@users.noreply.github.com
          git add -A data.json tranches.json macro.json macro_history.json watch.json
          git diff --staged --quiet && echo "변경 없음" && exit 0
          git commit -m "데이터 갱신"
          for i in 1 2 3; do
            git fetch origin main
            git rebase origin/main || { git rebase --abort; exit 1; }
            git push && exit 0
            sleep 5
          done
          exit 1
```
